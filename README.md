# Ecommerce-tests com 🎭Playwright
Projeto de Automação de Testes E2E e API utilizando o framework de testes automatizados **🎭Playwright**. 
<br>Desenvolvido sobre o portal: [Automation Exercise](https://automationexercise.com), que permite explorar a **intarface do usuário** e **API** em um contexto de **E-commerce**.
<p>O objetivo é demonstrar, na prática, estratégias de teste que podem ser aplicadas a produtos digitais de comércio eletrônico, combinando testes funcionais, API, automação E2E e integração com CI/CD.</p>

<h2>🛠️Para esse projeto utilizei</h2>

- Playwright
- TypeScript 
- Node.js
- Page Objects Model
- Fixtures 
- Faker
  
<h2>🎯Objetivos</h2>

- Identificar cenários de maior risco para o negócio
- Validar as principais jornadas de compra de um e-commerce
- Automatizar cenários críticos utilizando Playwright
- Executar os testes de forma automatizada através de CI/CD
- Produzir evidências e relatórios dos resultados.
